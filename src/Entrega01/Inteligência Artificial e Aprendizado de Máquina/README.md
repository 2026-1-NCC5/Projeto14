# 👁️ Detector - Lideranças Empáticas (Módulo de Visão Computacional)

Este diretório contém o modelo de visão computacional treinado com YOLO11 para a identificação em tempo real de itens, como Arroz, Feijão e Espaguete. 

Este módulo faz parte da **Entrega 01** do Projeto Interdisciplinar.

## 🛠️ Pré-requisitos

Antes de rodar o projeto, certifique-se de ter o Python instalado. Para instalar todas as dependências necessárias, abra o terminal nesta pasta e execute:

```bash
pip install -r requirements.txt
